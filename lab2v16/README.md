## 3. Контрольні запитання

1. **Що таке перевантаження конструкторів?**
   *Відповідь:* Це створення декількох конструкторів з однаковим ім'ям, але різним набором параметрів.

2. **Навіщо використовувати конструкцію `: this(...)`?**
   *Відповідь:* Для ланцюгового виклику одного конструктора з іншого, щоб уникнути дублювання коду.

3. **Хто та коли викликає деструктор `~SportTeam()`?**
   *Відповідь:* Збирач сміття (Garbage Collector), коли об'єкт видаляється з пам'яті.

4. **Чому ми додали перевірку в сеттер `PlayersCount`?**
   *Відповідь:* Для інкапсуляції та валідації даних, щоб значення не було від'ємним.
