# Самостійна робота №13: PLINQ (Parallel LINQ)

Проєкт досліджує ефективність паралельних обчислень за допомогою **PLINQ**, порівнює швидкість виконання трудомістких задач зі звичайним LINQ на обсягах від 1 до 10 мільйонів елементів, а також демонструє проблеми потокобезпеки (race condition) та методи їх усунення.

Детальні результати замірів та висновки містяться у файлі [REPORT.md](REPORT.md).
