# Самостійна робота №15: Реалізація exponential backoff

Проєкт містить власну реалізацію узагальненого класу `RetryPolicy<T>` з експоненційною затримкою, випадковим `jitter` та керуванням винятками через делегати. Демонструє сценарії відновлення після тимчасових збоїв та поведінку при вичерпанні ліміту спроб.

Детальний звіт та висновки містяться у файлі [REPORT.md](REPORT.md).
