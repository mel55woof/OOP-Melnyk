# Самостійна робота №14: Кейси Polly / Retry

Проєкт досліджує практичне застосування бібліотеки **Polly** у .NET для забезпечення відмовостійкості розподілених систем, обробки транзиторних збоїв за допомогою політик `Retry` та `Timeout`, а також аналізує правила побудови безпечних конвеєрів стійкості (`ResiliencePipelineBuilder`).

Детальний звіт, сценарії та відповіді на контрольні запитання містяться у файлі [REPORT.md](REPORT.md).
