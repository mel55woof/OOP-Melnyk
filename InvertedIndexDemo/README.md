# Самостійна робота №11: Інвертований індекс і вимірювання продуктивності

Консольний застосунок реалізує класичну структуру **Inverted Index** на базі `Dictionary<string, HashSet<int>>` для повнотекстового пошуку, а також містить модуль бенчмаркінгу продуктивності у порівнянні з лінійним пошуком (`Linear Search`).

Детальні результати вимірювань для 10, 100, 1000 і 10000 документів та висновки знаходяться у файлі [REPORT.md](REPORT.md).
