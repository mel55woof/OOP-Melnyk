# Самостійна робота №11: Інвертований індекс і вимірювання продуктивності

## Огляд проєкту
Консольний застосунок реалізує класичну структуру даних **Inverted Index** (інвертований індекс) на базі `Dictionary<string, HashSet<int>>` для швидкого повнотекстового пошуку за ключовими словами. 

Проєкт включає:
- Клас **`Document`** для представлення документів із унікальним ідентифікатором, заголовком та вмістом.
- Клас **`InvertedIndex`** із підтримкою методів додавання документів, пошуку за одним словом, а також множинного пошуку за декількома словами з використанням логічних операцій **AND** (`IntersectWith`) та **OR** (`UnionWith`).
- Статичний клас **`TextProcessor`** для токенізації тексту (регулярні вирази, переведення в нижній регістр) та фільтрації стоп-слов.
- Модуль бенчмаркінгу **`PerformanceTest`**, що порівнює швидкодію лінійного пошуку та інвертованого індексу на обсягах **10, 100, 1000 і 10000 документів**.
