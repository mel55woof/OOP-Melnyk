## 4. Контрольні запитання
Що таке клас та об’єкт? Яка між ними різниця?
Клас- це шаблон/креслення, що описує структуру та поведінку.
Об’єкт- це конкретний екземпляр класу в пам'яті.

Для чого використовуються конструктори? Чи може клас існувати без них?
Конструктори ініціалізують початковий стан об'єкта під час створення (new). Якщо конструктор не написати, C# створить конструктор за замовчуванням автоматично.

Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?
Приватне поле зберігає дані всередині класу, а публічна властивість контролює доступ до них (get/set). Інкапсуляція захищає дані від некоректних змін.
