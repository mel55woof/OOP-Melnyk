## 1. Відповіді на контрольні запитання

### Чому делегати є зручним механізмом для передавання поведінки в узагальнені методи?
Делегати дозволяють передавати методу не просто набір даних, а саму логіку (функцію або блок коду). Це дає змогу повністю відокремити універсальний алгоритм обробки колекції (наприклад, перебір елементів у циклі `foreach`) від конкретного правила чи критерію фільтрації/перетворення, який визначається під час виклику.

### У чому різниця між Func<T, TResult>, Action<T> та Predicate<T>?
- **`Func<T, TResult>`** — приймає аргумент типу `T` та обов'язково повертає результат типу `TResult` (використовується для операцій перетворення/мапінгу).
- **`Action<T>`** — приймає аргумент типу `T`, але нічого не повертає (`void`) — застосовується для виконання певної дії над елементами (наприклад, виведення в консоль).
- **`Predicate<T>`** — приймає аргумент типу `T` і завжди повертає логічне значення `bool` (використовується для перевірки умов та фільтрації).

### Які переваги дає поєднання generic-методів і лямбда-виразів під час роботи з колекціями?
- **Універсальність (Generic):** Забезпечує роботу одного й того самого методу з колекціями будь-яких типів (`int`, `string`, власними класами на кшталт `Product`) без дублювання коду.
- **Лаконічність (Лямбди):** Дозволяють передавати анонімні функції в один рядок замість створення громіздких окремих методів чи класів, що значно покращує читабельність коду.

### У яких випадках власні утиліти на кшталт Map чи Filter корисно реалізувати самостійно, навіть якщо існує LINQ?
Самостійна реалізація корисна для глибокого розуміння внутрішньої архітектури .NET та принципів функційного програмування, для оптимізації під специфічні алгоритмічні задачі, а також під час розробки власних легких мікрофреймворків без підключення важких бібліотек.

## 2. Порівняння власних утиліт з вбудованими LINQ-операторами

| Метод утиліти | Аналог у LINQ | Призначення |
| :--- | :--- | :--- |
| **`Map`** | `.Select()` | Трансформує кожен елемент колекції за заданим правилом |
| **`Filter`** | `.Where()` | Повертає лише ті елементи, які задоволенують умову (`predicate`) |
| **`MaxBy`** | `.MaxBy()` (.NET 6+) | Знаходить елемент із найбільшим значенням ключа |
| **`ForEach`** | метод `.ForEach()` (у `List<T>`) | Виконує дію для кожного елемента послідовності |
